# LIVIO 要件定義書

## 1. プロジェクト概要

### プロジェクト名
LIVIO
#### プロジェクト名の由来
Life + View
日々の生活を一つの画面から見渡せるアプリ

### コンセプト
「毎日開きたくなる、生活をまとめるアプリ」

予定・ToDo・家計簿・メモなど、日常生活で利用する機能を1つのアプリにまとめ、管理をより簡単にすることを目的とする。

---

## 2. 開発背景

普段、予定・ToDo・家計簿・メモをそれぞれ別のアプリで管理している。

- カレンダーアプリ
- ToDoアプリ
- 家計簿アプリ
- メモアプリ

複数のアプリを行き来する必要があり、「今日やること」や「生活全体」を一目で把握しにくいという課題がある。

そこで、生活に必要な情報を一つのアプリで管理できるサービスを開発する。

また、本プロジェクトを通して、Webアプリケーション開発に必要な設計・実装・公開までの一連の流れを学ぶことも目的とする。

---

## 3. 開発目的

### ユーザー視点

- 複数アプリを切り替える手間を減らす
- 今日必要な情報を一画面で確認できる
- 日常生活を効率的に管理できる

### 開発者視点

以下の技術を習得する。

- Next.js
- React
- TypeScript
- Express.js
- Prisma
- Docker
- Git / GitHub
- AWS EC2
